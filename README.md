# KPI Schedule App (Practical 1)

Мобільний iOS-застосунок для перегляду розкладу в КПІ. Дозволяє переглядати пари на тиждень, розрізняти їх за типами, бачити викладачів, аудиторії та одразу переходити на онлайн-пари по кліку.

---

* **Версія XCode:** 15.6
* **Мінімальна версія IOS:** 17.4
* **Тег для перевірки:** `practical-1`

--- 

# Що реалізовано згідно вимог:

Усе розписано по файлах відповідно до завдань:

### 1. Протоколи та Enum (`kpi_scheduleApp.swift`)
- **`ScheduleItem` (Protocol):** задає загальну структуру для занять (`id` та метод `getDetails()`).
- **`LessonType` та `WeekType` (Enum):** переліки для типів пар (лекція, практика, лаба) та тижнів (перший/другий).

### 2. Структури та Класи (`kpi_scheduleApp.swift`)
- **`Lesson` (struct):** звичайна структура (value type), яка описує конкретне заняття.
- **`DailySchedule` (class):** клас (reference type), який тримає масив пар на конкретний день (`lessons`) і має методи для їх додавання чи фільтрації.

### 3. Змінні, константи та ініціалізація
- Де треба - використовуються незмінні `let` (наприклад, `id`), де треба - змінні `var`.
- У класах та структурах прописані кастомні конструктори `init()`.

### 4. Опціонали та безпечне розгортання
- Аудиторія (`room`) та посилання на пару (`link`) зроблені опціональними (`String?`), адже вони є не завжди.
- Для безпечного витягування використовуються `??` та `if let` при кліку на лінк.

### 5. Колекції та умови
- Використовуються масиви (`[Lesson]`, `[DailySchedule]`).
- Умови (`if / else`) перевіряють, чи є пари в цей день (якщо треба вивести список пар в консоль).

### 6. Інтерфейс (`ContentView.swift`)
- Зроблено через `NavigationView` та `List`, а дні розбиті за секціями (`Section`).
- Винесено окрему компоненту картки (`LessonRowView`).
- Вся плашка пари клікабельні: якщо є посилання, то спрацьовує `@Environment(\.openURL)`.

## Інструкція з запуску
1. Клонуйте репозиторій або завантажте архів проєкту.
2. Відкрийте файл `kpi-schedule.xcodeproj` у середовищі **Xcode** (при створенні проєкту використовувався XCode 15.6).
3. Оберіть бажаний симулятор (наприклад, **iPhone 15**).
4. Натисніть кнопку **Run (Play)** або комбінацію клавіш `Cmd + R`.
